# README

## 目的

本セクションは、システムが扱う**ドメイン知識および概念構造**を定義することを目的とする。  
実装詳細や技術選定ではなく、**業務・概念レベルでの構造と意味**を明確にする。

本セクションは、設計判断や実装方針の前提となる共通理解を提供する。

---

## 記載内容

本セクションには、以下の情報を含む。

- ドメインモデル図
  - エンティティ
  - 値オブジェクト
  - 集約
  - 概念間の関係性
  - 不変条件（invariant）
- 同じ言葉集（ユビキタス言語）の定義
  - ドメイン用語の意味
  - 用語の統一された使い方
- ドメインモデル図の読み方・前提

---

## 記載しないこと

本セクションでは、以下の内容は扱わない。

- API仕様やエンドポイント定義
- データベース設計やテーブル構造
- 実装クラスやフレームワーク依存の説明
- ドメインスコープ外の概念や将来検討中の仕様

これらは誤解や責務の混在を防ぐため、意図的に除外する。

---

## 位置づけ

本セクションは、システム全体の**設計・実装の基盤**となる位置づけを持つ。

- 実装（application / infrastructure）よりも上位概念を扱う
- API やユースケース設計の前提となる
- 設計判断の背景は ADR を参照する

---

## 特徴やルール

- 本セクションで定義された用語は、以降のドキュメントで優先的に使用する
- 同一概念に複数の呼称を与えない
- ドメインモデル図は「現行仕様」を表すものとする
- 不変条件は、可能な限りドメインモデル上で明示する
- スコープ外の概念は README または用語集で明確に区別する
