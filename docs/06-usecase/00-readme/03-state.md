## 目的

本ドキュメントは、ユースケース実行中に発生する状態の変化を整理し、  
「今どの状態にあるのか」「次に何が起こり得るのか」を共通認識として持つことを目的とする。

処理の成否やユーザー体験を、状態遷移という観点から理解できるようにする。

## 記載内容

**状態遷移図**

- 状態遷移図、あるいは表形式で視覚的に理解を促す

**状態の一覧**

- ユースケース中に登場する代表的な状態（例: idle / loading / completed / error など）
- 値、説明、意味を記載すること

**状態遷移の条件**

- どの操作・出来事によって状態が遷移するか
- 正常系・異常系それぞれの代表的な遷移

**状態ごとの意味**

- 各状態が示す業務的・体験的な意味

---

## 記載しないこと

- 画面コンポーネントの実装詳細
- API 名、HTTP メソッド、通信仕様
- 内部ロジックや例外処理の細かい分岐

---

## 位置づけ

- overview で示されたユースケースを、状態の観点で具体化するドキュメント
- sequence.md と並び、動的な振る舞いを理解するための補助資料
- 実装前の認識合わせ、およびテスト観点整理の基礎資料

---

## 特徴やルール

- 状態は「ユーザー・業務視点」で命名する
- 技術的な内部状態は原則として表に出さない
- すべての状態は、開始状態と終了状態のどちらかに接続されていること
- 不明確な状態は新設せず、既存状態の意味を明確化する
- 状態遷移がない場合は記載不要
