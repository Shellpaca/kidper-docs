## 目的

本ドキュメントは、特定の業務ユースケースにおける全体像を短時間で把握できるようにすることを目的とする。  
詳細仕様や処理フローに入る前段として、ユースケースの背景・成立条件・完了状態を明確にする。

## 記載内容

**ユースケースの目的**

- このユースケースが解決しようとしている業務上の課題

**想定ユーザー**

- 実際に操作・関与する利用者の種別

**前提条件**

- ユースケース開始時点で満たされているべき条件

**完了条件**

- ユースケースが正常に完了したと判断できる状態

---

## 記載しないこと

- 画面遷移や操作手順の詳細
- 正常系・異常系の時系列フロー
- API、HTTP、イベントなどのインターフェース仕様
- 内部処理の分岐や技術的な実装内容

---

## 位置づけ

- ユースケース配下ドキュメントの最初に読むべき入口ドキュメント
- 非エンジニアを含めた関係者が、「このユースケースは何をするものか」を合意するための資料
- 詳細仕様（sequence / state / rules 等）への導線

---

## 特徴やルール

- 1ユースケースにつき1ファイルとする
- 簡潔かつ抽象度を保ち、詳細に踏み込みすぎない
- 技術用語の使用は最小限に留める
- 専門用語はユビキタス言語を使用する
- 「何をするか」「いつ完了とみなすか」を明確に記述する
