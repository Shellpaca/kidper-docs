## 目的

本ドキュメントは、このユースケースにおいて  
バックエンドが守るべき責務・保証・判断を明文化することを目的とする。

domain/ に定義されたドメインルールを、  
「このユースケースでどのように強制するか」を示す契約仕様である。

---

## 記載内容

- バックエンドの責務範囲
  - 何を保証するか
  - 何を保証しないか
- 入力値の最終検証方針
  - 信頼境界
  - 必須条件
  - 拒否条件
- ユースケース処理ポリシー
  - 冪等性
  - 重複処理の扱い
  - 実行順序の保証
- トランザクション・整合性方針
  - トランザクション境界
  - 補償処理の有無
- 永続化・外部連携の責務
  - 成功条件
  - 失敗時の扱い
- エラーハンドリング方針
  - 業務エラー
  - システムエラー

---

## 記載しないこと

- Controller / Service / UseCase のクラス構成
- フレームワークやライブラリ固有の設定
- SQL / DB スキーマ / ストレージ構成
- ドメインモデルの再説明や図の再掲

---

## 位置づけ

- バックエンド実装者向けの契約仕様書
- frontend.md と対になる責務定義
- domain のルールをユースケースに適用するための指針

---

## 特徴やルール

- バックエンドは「業務的な正しさ」を保証する
- フロントエンドの入力は信頼しない
- ドメインルール違反は必ず検知・拒否する
- 技術詳細ではなく「振る舞い」を記述する
