# READMEの書き方

各セクションには、必ず README を設けること。
README は、そのセクションに初めて来た人が
**「ここに何が書いてあり、どこを読めばよいか」**を判断するための入口である。

README は詳細仕様を書く場所ではなく、**案内・前提・範囲の明示**に責任を持つ。

---

## テンプレート

```txt
## 目的


---

## 記載内容

-

---

## 記載しないこと

-

---

## 位置づけ

-

---

## 特徴やルール

-

---

```

---

## READMEの役割

README は、次の問いに答えることを目的とする。

- このセクションは何を扱うのか
- どこまでが対象範囲か
- 何が書いてあり、何が書いていないのか
- 次にどのドキュメントを読むべきか

---

## 基本ルール

- 各ディレクトリ（またはセクション）に1つ README を置く
- README はその配下のドキュメントを要約・案内する
- README 自体に詳細仕様を書かない
- 判断・背景・前提条件を簡潔に示す

---

## 各セクションの書き方

### 目的

このセクションが存在する理由を書く。
何を解決するための情報かを明示し、設計・実装・運用のどれに寄与するかを示す。

背景の詳細説明や個別仕様の列挙は書かない。

---

### 記載内容

このセクション配下に存在するドキュメントの概要を列挙する。

- 扱っている主なトピック
- ドキュメントの種類
- 推奨される読み順（必要な場合）

---

### 記載しないこと

意図的に書かない内容を明示する。

- 他セクションと重複する説明
- 範囲の示す

この項目は、誤読を防ぐために必ず記載する。

---

### 位置づけ

このセクションが全体構成の中でどこに位置するかを示す。

- 上位・下位セクションとの関係
- 前提として読むべきドキュメント
- 関連する ADR や設計資料

---

### 特徴やルール

このセクション特有の前提や制約を記載する。

- 命名規則
- 設計方針
- 実装・運用上の注意点
